# CyberOrchestra Evaluation

This directory is reserved for benchmark tooling and generated evaluation output. The project compares CyberOrchestra analysis with a single-LLM baseline where the implemented evaluation path and required model configuration are available.

Any built-in benchmark scenarios are synthetic simulations. They must remain clearly labelled as simulations and must not be presented as real incidents. Evaluation output is generated locally and ignored by Git; `results/.gitkeep` preserves the output directory.

See the repository [README](../README.md) for setup and test commands.
