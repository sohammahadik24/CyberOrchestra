# CyberOrchestra Frontend

React, TypeScript, and Vite dashboard for the CyberOrchestra FastAPI service.

## Local setup

From this directory:

```powershell
npm ci
npm run dev -- --host 127.0.0.1
```

Create a production build with `npm run build`. The development server prints the local URL. Start the backend separately; see the repository [README](../README.md) for the full setup.
